# 周报（9.12-9.19）

## 本周阅读 论文

| 论文／成果                                                   | 发表时间 / 出处     | 核心贡献 / 新方法                                            | 适用方向（LLM / VLM / 跨模态）       | 局限或未来挑战                                               | 当前状态   |
| ------------------------------------------------------------ | ------------------- | ------------------------------------------------------------ | ------------------------------------ | ------------------------------------------------------------ | ---------- |
| **VLA-Mark: A cross modal watermark for large vision-language alignment model** | 最近一个月（arXiv） | - 首个针对 **视觉-语言对齐模型** 的跨模态文本水印方法<br>- 利用 VLA 架构的视觉-文本对齐机制，识别 **语义关键 token (SCTs)**<br>- 基于生成不确定性（entropy）动态调节水印强度<br>- 在保持图像与文本语义一致性的同时，提高对抗 **paraphrase / synonym / translation** 等攻击的能力 | 跨模态 / VLM + LLM 混合（视觉-语言） | - 在极端低 entropy 或文本高度编辑／重写的场景下，效果可能受限<br>- 实现复杂度较高，对不同基线方法的泛化性需更多实验证明 | 已完成阅读 |
| **Watermarking Large Language Models: An Unbiased and Low-risk Method (STA-1)** | ACL 2025 长文       | - 提出 **STA-1 方法**：一种“无偏 / 低风险”的 LLM 输出水印<br>- 保持 token 分布期望不变（unbiased），减少水印对输出质量的影响<br>- 在低 entropy 场景下，相比其他方法更能保持文本质量<br>- 检测效率高，且对白盒 / 黑盒 API 依赖较小 | LLM 水印（纯文本生成）               | - 在极端攻击或大规模文本编辑下，鲁棒性有待验证<br>- 水印强度与用户阅读 / 理解体验之间的权衡仍需进一步优化 | 已完成阅读 |
| **BiMark: Unbiased Multilayer Watermarking for Large Language Models** | 近期（arXiv ）      | - 提出 **多层水印机制**，结合 **无偏重加权 (unbiased reweighting)** 与 **位置分配策略 (position allocation)**，在不同生成层面嵌入水印<br>- 解决了单一方法在 **文本质量 vs 水印鲁棒性** 上的矛盾<br>- 提高了在多种攻击场景下（重写 / 改写 / 翻译）的检测准确率 | LLM 水印（多层嵌入）                 | - 实现复杂度更高，训练与推理开销增加<br>- 如何平衡多层水印的“强度 vs 可读性”仍是挑战 | 正在阅读中 |

---

## 本周收获

- **VLA-Mark** 开启了 **跨模态水印** 的研究方向。  
- **STA-1** 聚焦 **低风险无偏水印**，在 LLM 中改善低 entropy 场景的质量。  
- **BiMark** 尝试通过 **多层嵌入** 来兼顾鲁棒性与文本质量，是 STA-1 的进一步拓展。
