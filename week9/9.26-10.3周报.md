# 9.26-10.3周报：Watermarking Vision-Language Pre-trained Models for Multi-modal Embedding as a Service

## 1. 研究背景
- Vision-Language Pre-trained Models (VLPs)，如 **CLIP**，能对图像与文本进行跨模态对齐，广泛用于检索、分类、检测。  
- 越来越多公司将 VLPs 封装为 **Embedding as a Service (EaaS)** 提供给开发者。  
- **风险**：EaaS 易遭遇 **模型提取攻击** —— 攻击者调用 API 收集输入输出对，用来训练盗版模型。  
- **挑战**：现有水印（参数型、指纹型、后门型）方法多为分类或单模态，难以在多模态 embedding + 黑箱环境下使用。  

---

## 2. 贡献与创新
- 提出 **VLPMarker**，首个针对 **多模态 EaaS** 的水印方法。  
- 创新点：
  1. **正交变换注入**：学习一个接近正交的线性变换矩阵，将触发器嵌入 embedding 空间，最小化对性能的影响。  
  2. **OoD 触发器选择**：利用公开数据构造“分布外”触发器，避免依赖训练集。  
  3. **协作验证策略**：结合触发器检测和 embedding 分布比对，增强鲁棒性。  
  4. **黑箱可验证**：仅需 API 调用即可检测盗版，无需访问模型参数。  
  5. **多用户识别**：可为不同用户分配不同变换矩阵，实现水印溯源。  

---

## 3. 方法概览
1. **触发器选择**  
   - 从公开语料统计高频类，构造 2–3 类组合的 OoD 图文对。  
   - 保证触发器稀有但可继承，不影响正常 embedding 结构。  

2. **水印注入**  
   - 优化目标：  
     \[
     W_{\text{align}} = \arg\min_W \| WV - WT \|_F^2
     \]  
     其中 \(V, T\) 是触发器的图像/文本 embedding。  
   - 正交修正：  
     \[
     W \leftarrow (1+\beta)W - \beta (WW^\top)W
     \]  
     使 \(W\) 接近正交，保持 embedding 结构。  
   - 输出：\(E_p = W_{\text{align}} E_o\)。  

3. **版权验证**  
   - **触发器检测**：比较触发器在原始服务与可疑服务中的相似度差异（Δ_cos、Δ_l2、KS p-value）。  
   - **分布验证**：用 \(W^{-1}\) 将可疑 embedding 映回伪原始空间，计算整体平均余弦相似度 \(C_{\text{avg}}\)。  
   - 两者结合，提高鲁棒性。  

---

## 4. 实验结果
- **数据集**：MS-COCO、Flickr30k、CIFAR-10/100、ImageNet-1K、VOC2007。  
- **对比基线**：Original、EmbMarker、Random。  

**主要发现**：  
1. **性能保持**：VLPMarker 几乎不降低下游任务精度；EmbMarker 严重下降。  
2. **鲁棒检测**：VLPMarker 的 Δ_cos > 0.4，p-value 很低，可稳定检测。  
3. **模型规模**：适用于 CLIP Base / Large / Huge。  
4. **触发数影响**：32–64 效果最佳；过小 → 过拟合，过大 → 欠拟合。  
5. **可视化**：VLPMarker 的 embedding 空间与原始空间几乎“旋转”关系，隐蔽性强。  
6. **抗攻击性**：  
   - 抵御模型提取攻击（OpenCLIP 模拟）。  
   - 抵御相似性不变攻击（维度平移、缩放）。  
7. **多用户识别**：1024 用户场景下，识别准确率 = 100%。  

---

## 5. 结论与未来工作
- **结论**：VLPMarker 在保证下游性能的前提下，实现了黑箱条件下对多模态 EaaS 的有效、鲁棒的版权保护。  
- **未来方向**：探索更高效的变换式水印方法，提升在极端攻击条件下的鲁棒性，降低触发器依赖。
